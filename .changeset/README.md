# Changesets

Add a changeset for user-facing changes to the published `rosetta-date` package:

```sh
pnpm changeset
```

Select the package, choose the semver impact, and describe the change for package users. Internal
workspace maintenance does not need a changeset unless it belongs in the release notes.

See the [Changesets documentation](https://github.com/changesets/changesets/blob/main/docs/common-questions.md)
for release and versioning details.
